# Web3 & AI 训练营 - 学习工作区

这是一个专门为 Web3 & AI 训练营创建的统一工作区，用于记录从 Week 1 开始的所有课程实验、学习笔记、Demo、Prompt、Agent 配置和复盘记录。

## 1. 工具准备清单

### 协作工具
- **GitHub**: 代码托管与成果提交的核心入口。
  - **用途**: 管理代码版本，记录每周学习进度，提交 Commit 记录作为学习证明。
- **Trae IDE**: 智能开发环境（IDE）。
  - **用途**: 利用其内置的 AI 能力进行代码编写、文件管理和终端操作，是本次学习的主要工作台。

### AI 工具
- **Claude Code**: Anthropic 推出的命令行 AI 助手。
  - **用途**: 用于深度代码理解、跨文件重构以及复杂的编程逻辑咨询。
- **Cursor**: 集成了 AI 的代码编辑器。
  - **用途**: 利用其 Tab 补全和 Composer 功能快速构建项目原型和调试代码。
- **OpenAI Codex (CLI)**: 已安装验证 (`codex-cli`)。
  - **用途**: 在终端执行自然语言指令，快速生成基础代码片段。
- **Hermes**: 高性能 AI 模型/工具。
  - **用途**: 辅助进行逻辑推理、文档总结以及更精准的 Prompt 调试。

### Web3 工具
- **MetaMask (小狐狸钱包)**: 核心 Web3 入口。
  - **用途**: 管理测试网资产（如 Sepolia ETH），进行 DApp 登录授权及智能合约交互签名。
- **Web3.js / Web3.py**: 区块链开发库。
  - **用途**: 在代码中调用区块链节点 API，读取链上数据（如余额、合约状态）并发送交易。

## 2. Week 1 学习与实践任务应用
- **环境连通**: 使用 GitHub 管理本地代码，通过 Trae 终端操作 Git 推送。
- **AI 辅助编程**: 尝试让 Claude Code 或 Cursor 解释 Web3 合约代码，并使用 Codex 快速生成简单的查询脚本。
- **钱包交互**: 配置 MetaMask 连接到测试网，并准备好 Web3 库的调用环境。
